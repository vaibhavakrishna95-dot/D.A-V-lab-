# D.A-V-lab-
\**tennis_correlation_analysis.py**\ 
loads /content/tennis.csv, checks missing values, drops duplicate rows, encodes categorical features numerically, and reports the strongest positive and negative correlations.
\**titanic_survival_visualization.py**\
fetches the Titanic dataset via fetch_openml, cleans survival, age, fare, and sex fields, and plots gender survival counts, age-versus-fare scatter plots, density distributions, and a pair plot.
\**iris_statistical_analysis.py**\
loads the Iris dataset to compute mean, median, mode, standard deviation, standard error, and 95% confidence intervals, alongside a correlation heatmap, sepal-petal covariance, and a binned sepal length contingency table.
